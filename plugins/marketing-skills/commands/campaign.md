# /campaign

1. Confirm the brief is approved and read `context.md` + `brand-voice.md`.
2. Hand off to the `canva-creator` skill to build the posting calendar, generate
   social designs, and draft caption/email copy — every step gated on owner
   approval.
3. Pull seasonal timing from context (e.g. RO gifting peaks) when scheduling.
4. Stage sends per the skill; save assets to `/outputs`; summarize what's queued.
